# TOA Verifier

Compact mobile receiving tool for counting fiber, orange copper, and green copper by position.

## Run locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Features

- Add position codes such as `02-02-020-54`
- Compact inline quantity controls
- Type quantities directly or use plus/minus buttons
- Automatic numerical sorting by position segment
- Overall position count
- Persistent browser storage
- Copy, preview, and download a sorted text report
- Responsive, offline-ready PWA
